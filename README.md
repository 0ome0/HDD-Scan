# HDD-Scan — พื้นที่ดิสก์หายไปไหน

แอป Windows สำหรับหาว่าพื้นที่ไดรฟ์ถูกใช้ไปกับโฟลเดอร์ไหน เท่าไหร่ และมาจากการใช้งานแบบไหน

## วิธีใช้

1. ดับเบิลคลิก `HddScan.exe` (ไม่ต้องติดตั้ง และไม่ต้องลง .NET)
2. เลือกไดรฟ์ (ค่าเริ่มต้นคือ C:) หรือกด **เลือกโฟลเดอร์…** แล้วกด **▶ สแกน**
3. ถ้าต้องการตัวเลขครบที่สุด ให้กด **รันแบบ Admin** ก่อนสแกน (ไม่งั้นบางโฟลเดอร์ของระบบจะเข้าไม่ได้)

> ครั้งแรกที่เปิด Windows SmartScreen อาจเตือนว่าเป็นแอปที่ไม่รู้จัก ให้กด **More info → Run anyway**

## แท็บต่างๆ

| แท็บ | ใช้ทำอะไร |
|---|---|
| **โฟลเดอร์** | ต้นไม้โฟลเดอร์เรียงจากใหญ่ไปเล็ก ด้านขวาแสดงโฟลเดอร์ย่อยและไฟล์ พร้อมแถบสัดส่วน |
| **Treemap** | แผนภาพกล่องสี กล่องยิ่งใหญ่ยิ่งกินพื้นที่ สีบอกหมวดการใช้งาน (คลิกซ้าย = เข้าไปดู, คลิกขวา = ย้อนขึ้น) |
| **ตัวการที่พบบ่อย** | ตรวจจุดที่มักกินพื้นที่ให้อัตโนมัติ เช่น Temp, Recycle Bin, Windows.old, hiberfil.sys, แคชเบราว์เซอร์, Docker/WSL, node_modules, แคช npm/NuGet/Gradle, เกม และ OneDrive พร้อมป้าย ✔ ลบได้ / ⚠ ระวัง / ⛔ ห้ามลบเอง และวิธีจัดการ |
| **ตามการใช้งาน** | แยกพื้นที่ตามที่มา: Windows, โปรแกรม, เกม, Dev, Docker/WSL, เบราว์เซอร์, Temp, ไฟล์ส่วนตัว, AppData ฯลฯ |
| **ประเภทไฟล์** | แยกตามชนิด เช่น วิดีโอ, รูป, ไฟล์ติดตั้ง/ISO, ZIP, VM, ฐานข้อมูล และแยกตามนามสกุล |
| **ไฟล์ใหญ่สุด** | ไฟล์ใหญ่สุด 1,000 อันดับ กรองได้ตามขนาด อายุไฟล์ (ไม่ได้แก้ไขเกิน 3 เดือน – 2 ปี) ประเภท และคำค้น |
| **เทียบครั้งก่อน** | ทุกครั้งที่สแกน แอปจะเก็บสรุปไว้ สแกนซ้ำวันหลังแล้วจะเห็นว่าโฟลเดอร์ไหนโตขึ้นเท่าไหร่ |

คลิกขวาที่รายการเพื่อ **เปิดใน Explorer**, **คัดลอก path** หรือ **ย้ายไป Recycle Bin** (มีหน้ายืนยันก่อน และแอปจะไม่ยอมลบไฟล์ในโฟลเดอร์ Windows)
ปุ่ม **Export CSV** ใช้บันทึกผลไว้เปิดใน Excel

## ตัวเลขเชื่อถือได้แค่ไหน

- ข้าม junction/symlink เพื่อไม่ให้นับซ้ำ
- ไม่นับไฟล์ OneDrive ที่อยู่บนคลาวด์อย่างเดียว เพราะไม่ได้กินพื้นที่ในเครื่อง
- WinSxS อาจดูใหญ่เกินจริง เพราะมี hardlink ที่ใช้ร่วมกับ System32
- แถบสีส้มคือ "พื้นที่ที่สแกนมองไม่เห็น" ส่วนใหญ่เป็น System Restore/Shadow Copy หรือโฟลเดอร์ที่ไม่มีสิทธิ์เข้า

ประวัติการสแกนเก็บไว้ที่ `%LOCALAPPDATA%\HddScan\history`

## Build จาก source

ต้องมี .NET 8 SDK

```
cd src\HddScan
dotnet run -c Release
```

Build เป็น exe ไฟล์เดียว (self-contained):

```
dotnet publish src\HddScan -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```

## โครงสร้างโค้ด

```
src/HddScan/
  Core/Scanner.cs    สแกนแบบขนาน (FileSystemEnumerable) + top-N ไฟล์ + สถิตินามสกุล
  Core/Analysis.cs   หมวดการใช้งาน, ประเภทไฟล์, กฎ "ตัวการที่พบบ่อย"
  Core/History.cs    เก็บ/เทียบผลสแกนแต่ละครั้ง
  UI/MainForm.cs     หน้าจอหลัก (WinForms)
  UI/TreemapView.cs  Treemap แบบ squarified
  UI/BarListView.cs  ListView ที่มีแถบสัดส่วนและเรียงตามคอลัมน์ได้
```

แผนต่อไป: สแกนเร็วขึ้นด้วยการอ่าน NTFS MFT ตรงๆ (ต้องรันแบบ Admin), หาไฟล์ซ้ำ และแจ้งเตือนเมื่อพื้นที่เหลือน้อย
